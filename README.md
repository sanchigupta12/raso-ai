# Raso AI Landing Page

A modern, responsive landing website for **Raso AI** — an AI-powered Voice Assistant for restaurants that automates phone orders, reservations, and guest queries 24/7.

## 🎨 Design Features

- **Professional SaaS-style**: Inspired by OpenAI, Linear, Notion, and Descript
- **Clean Color Palette**: White, charcoal, and accent teal/amber
- **Smooth Scrolling**: Section-based layout with smooth transitions
- **Sticky Navigation**: Always accessible navigation bar with CTA buttons
- **Fully Responsive**: Optimized for mobile, tablet, and desktop
- **Dark Mode Toggle**: Switch between light and dark themes
- **Subtle Animations**: Hover effects and fade-in animations

## 📋 Sections Included

1. **Hero Section** - Compelling headline with Watch Demo CTA
2. **Key Benefits** - 6 benefit cards highlighting value propositions
3. **Core Features** - 9 feature cards showcasing product capabilities
4. **Demo Section** - Video placeholder with Book Demo button
5. **Integrations** - Partner logos (OpenTable, Toast, Square, etc.)
6. **Pricing** - 3 tier pricing (Essential, Premium, Enterprise)
7. **FAQ** - Accordion-style frequently asked questions
8. **Blog** - 3 featured blog posts
9. **About Us** - Team expertise and mission
10. **Contact** - Contact form and email link
11. **Footer** - Links, copyright, and social media

## 🚀 Getting Started

Simply open `index.html` in your browser to view the landing page. No build process required!

### Local Development

```bash
# View the site locally
open index.html

# Or use a local server
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## 🛠️ Technology Stack

- **HTML5** - Semantic markup
- **TailwindCSS** - Utility-first CSS framework (CDN)
- **JavaScript** - Interactive features (dark mode, FAQ accordion)
- **SVG Icons** - Scalable vector graphics
- **Responsive Design** - Mobile-first approach
